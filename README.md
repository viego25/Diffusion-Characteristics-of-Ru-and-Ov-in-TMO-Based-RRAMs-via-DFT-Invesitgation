## Data Availability and Repository Access

This repository provides example computational data, structural models, Quantum ESPRESSO input/output files, and supporting analysis associated with the research article:

**"Diffusion Characteristics of Ru and Oxygen Vacancies in Transition Metal Oxide (HfO₂ and ZrO₂)-Based RRAMs: A First-Principles Investigation."**

### Available Data

- **ZrO₂:** Example computational data are provided in this repository, including structural models, pristine and defect calculations, oxygen vacancy formation energies, Ru dopant formation energies, migration barriers, electronic structure calculations, and supporting analysis files.
- **HfO₂:** The corresponding computational datasets are not included in this repository. Researchers interested in obtaining the HfO₂ computational data may contact the first author directly.
